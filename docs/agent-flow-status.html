Changes since the last status page

Since version 1 of this page, at commit fd01f7f (15:20).

  • A live call transcript through an ElevenLabs webhook tool.
  • The daily planner check now starts one job per day and order. A job that a restart stopped no longer blocks its key.
  • The planner check and the draft list now use the same "due" rule.
  • Conformal ranges for a product's first 6 forecast weeks. Plain backtest coverage went from 84% to 92%, with the target at 90%.
  • Step 5 runs live through StepFun directly. Search specs, SMS drafts and the summary use it.
  • The LLM-agent lane passed the H3 gate on the test site with Step 3.7 Flash.
